# Mod List

A mods screen with search, details and a settings button.

A native mod for [Horizon](https://github.com/horizon-rust/horizon), the Rust rewrite of Minecraft: Java Edition.
Built with [horizon-mixins](https://github.com/horizon-rust/horizon-mixins).

Inspired by Mod Menu by TerraformersMC (MIT). This is not an official port and it is not affiliated with the original or with Mojang or Microsoft.

## Install

Download the `.hnmod` from the latest release, put it in `horizon-native-mods/` in your Horizon folder, and build:

```sh
horizon-launcher native-build --trust-native-code
```

Native mods run with full access to your computer. Read the source first.

Pinned to Horizon `c9d474d` (Nightly 2026-11-01).
